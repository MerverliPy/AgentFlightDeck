# Roadmap

This roadmap describes planned project direction for AgentFlightDeck. Items listed here are exploratory and subject to change.

## Phase 0: Concept Definition

- Define project vision
- Clarify target users
- Identify core orchestration concepts
- Document non-goals
- Establish repository governance files

## Phase 1: Architecture Planning

- Define agent role model
- Define swarm coordination concepts
- Define conversation orchestration concepts
- Define context and retrieval strategy at a conceptual level
- Define safety and oversight principles

## Phase 2: Interface Planning

- Explore possible user interaction models
- Define expected configuration concepts
- Define documentation structure
- Identify integration boundaries with opencode

## Phase 3: Prototype Planning

- Identify minimum viable project scope
- Define evaluation criteria
- Define agent coordination scenarios
- Define documentation requirements for an initial prototype

## Phase 4: Pre-Release Review

- Review safety assumptions
- Review project scope
- Review terminology
- Review contribution process
- Prepare release-readiness checklist

## Not Currently Planned

The following are not part of the current non-release repository scaffold:

- Production deployment
- Hosted services
- Backend service implementation
- CI/CD automation
- Package publishing
- Stable API commitments
