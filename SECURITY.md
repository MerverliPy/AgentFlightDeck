# Security Policy

## Project Status

AgentFlightDeck is currently in a non-release planning stage.

It should not be used for production systems, sensitive data processing, regulated environments, autonomous high-risk decisions, or mission-critical automation.

## Supported Versions

There are currently no supported release versions.

| Version | Supported |
|---|---|
| Unreleased | No |

## Reporting Security Issues

If you identify a security concern in the project documentation, planned design, or future architecture direction, please open a private security advisory if available, or contact the maintainers through the repository’s preferred contact method.

## Security Scope

Relevant security concerns may include:

- Unsafe autonomous agent behavior
- Unclear human oversight boundaries
- Risky handling of sensitive context
- Overbroad permissions
- Ambiguous agent delegation models
- Misleading production-readiness claims
- Unsafe assumptions around retrieval-augmented context

## Out of Scope

Because AgentFlightDeck does not currently provide a production implementation, the following are not yet applicable:

- Runtime vulnerability reports
- Dependency vulnerability reports
- Deployment security reports
- Package exploit reports

These areas may become relevant if implementation work begins.
